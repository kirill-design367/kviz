# Установка приёмника заявок на сервер

Сервер: `104.171.137.47` (IPv4), `2a03:6f00:a::2:afc6` (IPv6).
На нём уже работают сайт `aureadesign.ru` и другой telegram-бот — их ничего
из перечисленного не касается.

## Что ставится и куда

| Что                  | Куда                                   |
| -------------------- | -------------------------------------- |
| Код сервиса          | `/opt/aurea-kviz/app.py`               |
| Настройки с токеном  | `/etc/aurea-kviz/kviz.env` (права 600) |
| Данные и очередь     | `/var/lib/aurea-kviz/`                 |
| Служба               | `aurea-kviz.service`                   |
| Пользователь         | `aureakviz` (системный, без оболочки)  |
| Конфиг nginx         | отдельный файл `aurea-kviz.conf`       |

Ничего из существующего не переписывается. Если установщик встречает чужой файл
на своём пути — он останавливается и говорит об этом, а не «чинит».

## Шаг 1. Осмотр (ничего не меняет)

```bash
curl -fsSL https://raw.githubusercontent.com/kirill-design367/kviz/claude/aurea-quiz-landing-1i0c4o/server/survey.sh -o survey.sh
bash survey.sh 2>&1 | tee survey.log
```

## Шаг 2. DNS

Заведите поддомен `kviz.aureadesign.ru`:

```
A     kviz   104.171.137.47
AAAA  kviz   2a03:6f00:a::2:afc6
```

Поддомен нужен потому, что сайт открывается по https, а браузер не пустит
запрос с https-страницы на http-адрес. Без сертификата форма молча не отправится.

## Шаг 3. Установка

```bash
curl -fsSL https://raw.githubusercontent.com/kirill-design367/kviz/claude/aurea-quiz-landing-1i0c4o/server/install.sh -o install.sh
bash install.sh 2>&1 | tee install.log
```

Скрипт идемпотентен: запускайте сколько угодно раз.

## Шаг 4. Токен

```bash
nano /etc/aurea-kviz/kviz.env
```

Заполнить две строки:

```
AUREA_KVIZ_BOT_TOKEN=токен_от_BotFather
AUREA_KVIZ_CHAT_ID=ваш_числовой_id
```

Свой `chat_id` можно узнать, написав своему боту и открыв
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` — но только с машины, у которой
есть доступ к Telegram.

```bash
chmod 600 /etc/aurea-kviz/kviz.env
systemctl restart aurea-kviz
```

## Шаг 5. Проверка

```bash
# по какому пути сервис достучался до Telegram
journalctl -u aurea-kviz -n 30 --no-pager | grep -i telegram

# состояние сервиса
curl -s http://127.0.0.1:8787/api/health

# снаружи
curl -s https://kviz.aureadesign.ru/api/health

# тестовая заявка — придёт в Telegram
curl -s -X POST https://kviz.aureadesign.ru/api/lead \
  -H 'Content-Type: application/json' \
  -d '{"name":"Проверка","phone":"+79990000000","channel":"telegram",
       "answers":[{"question":"Что нужно сделать?","answer":"Сайт с нуля"}],
       "price":{"low":150000,"high":200000}}'
```

## Если заявка не ушла

Она не потеряна. Порядок такой: заявка пишется на диск с `fsync`, и только потом
сервис пробует отправить её в Telegram. Не ушедшие лежат в очереди и
переотправляются раз в минуту.

```bash
ls /var/lib/aurea-kviz/outbox/          # что не ушло
cat /var/lib/aurea-kviz/leads.jsonl     # все заявки за всё время
journalctl -u aurea-kviz -f             # что происходит сейчас
```

## Про IPv4 и IPv6

`api.telegram.org` из России не отвечает по IPv4, но отвечает по IPv6. Библиотека
Python сама перебирает адреса в порядке, который выдаёт система, и обычно первым
идёт нерабочий IPv4 — соединение висит до таймаута, и бот выглядит сломанным.

Поэтому семейство адресов задаётся явно (`FamilyHTTPSConnection` в `app.py`):
при старте сервис проверяет оба пути, пишет в журнал, какой отвечает, ходит по
рабочему и запоминает его. Если рабочий перестал отвечать — пробует второй.
Принудительно закрепить путь можно переменной `AUREA_KVIZ_IP_FAMILY=ipv6`.

## Полезные команды

```bash
systemctl status aurea-kviz          # состояние
systemctl restart aurea-kviz         # перезапуск
journalctl -u aurea-kviz -f          # живой журнал
journalctl -u aurea-kviz --since today
nginx -t && systemctl reload nginx   # после правок конфига
```

## Как снести, ничего чужого не задев

```bash
systemctl disable --now aurea-kviz
rm -f /etc/systemd/system/aurea-kviz.service
rm -f /etc/nginx/sites-enabled/aurea-kviz.conf /etc/nginx/sites-available/aurea-kviz.conf
rm -f /etc/nginx/conf.d/aurea-kviz.conf
systemctl daemon-reload && nginx -t && systemctl reload nginx
rm -rf /opt/aurea-kviz /etc/aurea-kviz
# /var/lib/aurea-kviz с заявками оставьте, если они ещё нужны
userdel aureakviz
```
