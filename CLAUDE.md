# CLAUDE.md — AUREA. Квиз-лендинг

Рабочий журнал и правила проекта. Ведётся по ходу работы.

## 1. Что это

Квиз-лендинг студии AUREA. Единственная задача — собирать заявки на разработку
сайтов из Яндекс Директа. Не портфолио, не визитка. Конверсия важнее всего
остального.

Путь пользователя: оффер → кнопка → 7 вопросов по одному на экран → вилка цены
(безусловно, до формы) → форма (имя, телефон, канал связи) → подтверждение.
Заявка уходит в Telegram владельцу.

## 2. Стек и деплой

- Next.js 15 (App Router), TypeScript, Tailwind 3, GSAP, Lenis.
- `output: 'export'` — статический экспорт, никакого рантайма Node на фронте.
- GitHub Pages через Actions (`.github/workflows/deploy.yml`), `basePath=/kviz`.
- Приёмник заявок — отдельный Python-сервис на сервере владельца (`server/`).

## 3. Жёсткие правила (нарушать нельзя)

- Латиница только в слове AUREA. Всё остальное — кириллица.
- Никаких восклицательных знаков, «оставьте заявку», «менеджер свяжется».
- Никаких выдуманных фактов о студии: клиенты, годы, отзывы, кейсы.
- Никаких таймеров обратного отсчёта и приёмов давления.
- Никакой фальшивой анимации «идёт расчёт». Вилка показывается сразу.
- Вилка считается ТОЛЬКО из вопросов 1, 5, 6. Вопрос 7 (бюджет) в расчёт
  не входит принципиально.
- Вилка показывается как диапазон, не как точная цифра.
- На сервере ничего чужого не трогать: ни конфигов nginx, ни юнитов systemd,
  ни файлов существующего сайта и бота.
- Токен бота в коде не фигурирует — только имя переменной окружения.

## 4. Качество

- Мобильная версия главная. PageSpeed 90+ на мобильной.
- 60 fps: анимируются только `transform` и `opacity`.
- Проверено на 1920×1080 и 390×844.
- `prefers-reduced-motion` выключает всё движение.
- Своя страница 404.

## 5. Карта репозитория


## 6. Журнал решений

- **Шрифты.** Кириллица проверена по таблице `cmap` файла шрифта
  (`scripts/check-cmap.py`), а не по описанию на сайте. Отчёт — в разделе 8.
- **Хранение ответов.** `localStorage`, ключ `aurea-kviz-v1`, с версией схемы.
  При несовпадении версии состояние сбрасывается.
- **Телефон.** Маска и валидация под российский формат, +7/8, 11 цифр.
- **Двойная отправка.** Блокируется состоянием `submitting` + `submitted`;
  повторный клик игнорируется.
- **Сохранность заявки.** Сервер пишет заявку на диск (fsync) ДО ответа
  браузеру. Telegram — уже после. Не ушло — лежит в outbox и ретраится.
- **IPv6.** `api.telegram.org` в РФ недоступен по IPv4, но доступен по IPv6.
  Сервис пробует оба пути и запоминает рабочий.

## 8. Отчёт по шрифтам (cmap)

Проверка — `scripts/check-cmap.py`, полный вывод — `docs/fonts-cmap.txt`.
Проверялись сами файлы шрифтов, а не описания подмножеств на сайте, и это
сразу дало два отвода:

- **Instrument Serif** — кириллицы нет вообще, 0 символов из блока U+0400–04FF.
- **Playfair Display** — кириллица полная, но нет знака рубля U+20BD. На экране
  вилки вместо ₽ был бы пустой прямоугольник.

Приняты:

- **Onest** — основная гарнитура. Полная русская кириллица, ₽, №, ось веса 100–900.
- **Cormorant Garamond** — только цифры вилки, номера вопросов и слово AUREA.
  Полная кириллица, ₽, ось веса 300–700.

Оба подмножества собраны `pyftsubset` под нужные диапазоны, вес переменный,
по 33 КБ каждый. Контраст палитры — `scripts/contrast.py`, вывод `docs/contrast.txt`.
