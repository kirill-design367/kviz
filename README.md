# AUREA · квиз-лендинг

Квиз-лендинг студии AUREA: семь вопросов о задаче, вилка цены сразу на экране
и заявка в Telegram. Сделан под платный трафик из Яндекс Директа.

Правила проекта и журнал решений — в [CLAUDE.md](./CLAUDE.md).

## Разработка

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # расчёт вилки: 64 комбинации и свойства модели
npm run typecheck
npm run build      # статический экспорт в out/
```

Переменные сборки:

| Переменная                  | Зачем                                        |
| --------------------------- | -------------------------------------------- |
| `NEXT_PUBLIC_BASE_PATH`     | префикс пути (нужен только для локальных проверок) |
| `NEXT_PUBLIC_LEAD_ENDPOINT` | адрес приёмника заявок                        |
| `NEXT_PUBLIC_YM_ID`         | номер счётчика Яндекс Метрики                 |
| `NEXT_PUBLIC_SITE_URL`      | канонический адрес для метатегов              |

## Сервер

`server/` — приёмник заявок и Telegram-бот. Только стандартная библиотека
Python 3, ставится своим пользователем и своей службой.

```bash
bash server/survey.sh     # осмотр сервера, только чтение
bash server/install.sh    # установка, идемпотентна
```

`server/install.sh` собирается из `server/install.template.sh` и `server/app.py`
командой `npm run installer` — править нужно их, а не готовый файл.
